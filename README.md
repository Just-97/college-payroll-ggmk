# Система расчета заработной платы преподавателей колледжа (Республика Беларусь)

Веб-приложение для расчета и учета заработной платы педагогических работников учреждений среднего специального образования (колледжей) Республики Беларусь в соответствии со статьей 80 ТК РБ, Указом Президента РБ № 27 и нормативными актами Министерства образования РБ.

## Основные возможности и роли системы

### 1. Личный кабинет преподавателя (Основной портал `/`)
* **Строгое разграничение:** преподаватель имеет доступ **исключительно к своему расчетному листку**.
* Выбор расчетного периода (месяц, год), архив прошлых выплат.
* Полная детализация всех составных частей:
  * Оплата часов по тарификации (норма 720 ч/год или 72 ч/месяц);
  * Отраслевая надбавка за специфику работы в сфере образования (40%);
  * Надбавка за квалификационную категорию (высшая, первая, вторая, методист);
  * Надбавка за стаж работы в бюджетных организациях (выслуга лет от базовой ставки);
  * Надбавка за кураторство учебной группы (классное руководство);
  * Надбавка за заведование учебным кабинетом / лабораторией / мастерской;
  * Доплата за проверку письменных работ и тетрадей;
  * Доплата за руководство цикловой комиссией (ЦК);
  * Стимулирующие и премиальные выплаты.
* Удержания в РБ:
  * Подоходный налог (13%) с учетом стандартных вычетов на детей;
  * Страховой пенсионный взнос в ФСЗН (1%);
  * Профсоюзный взнос (1%);
  * Выплаченный аванс за первую половину месяца.
* **Кнопка «Распечатать расчетный листок»:** адаптивный бланк по ст. 80 ТК РБ с реквизитами колледжа, суммами и местами для подписей (оптимизирован для печати А4 через `@media print` со скрытием навигации).

---

### 2. Рабочее место бухгалтера (Основной портал `/`)
* Сводная расчетная ведомость по всем преподавателям колледжа.
* Фильтрация по периодам, отделениям, быстрый поиск по ФИО и табельному номеру.
* Создание и редактирование начислений (живой калькулятор с моментальным пересчетом).
* **Модуль формул и нормативов:**
  * Настройка базовой ставки РБ (в BYN);
  * Настройка процентов за категорию, стаж, специфику образования, кураторство, кабинеты;
  * Ставки подоходного налога, ФСЗН и профсоюза;
  * Налоговые вычеты на детей.
* Штатное расписание преподавателей с возможностью добавления и редактирования.
* Экспорт сводной ведомости в формат CSV / Excel.

---

### 3. Кабинет администратора (Изолированная страница `/admin`)
* **Полная изоляция:** административная панель вынесена на отдельный маршрут (`#/admin`) с собственным строгим темно-изумрудным интерфейсом.
* Управление учетными записями пользователей:
  * Просмотр ФИО, email, логинов и **паролей** (с возможностью показать/скрыть);
  * Назначение ролей (`TEACHER`, `ACCOUNTANT`, `ADMIN`);
  * Привязка аккаунта к карточке преподавателя в штате (табельный номер);
  * Блокировка и удаление пользователей;
  * Генератор надежных паролей.
* Журнал безопасности и аудита действий в системе.

## Запуск проекта

```bash
# Установка зависимостей (уже установлены)
npm install

# Запуск локального сервера разработки
npm run dev

# Сборка проекта
npm run build
```

Приложение откроется по адресу: `http://localhost:5173/` (или указанному Vite порту).  
Для перехода в панель администратора: кликните на кнопку **«Кабинет администратора»** в шапке либо перейдите по ссылке `/#/admin`.
